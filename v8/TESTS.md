# Tests et Couverture de Code

## État actuel : 0.0% Coverage

**379 lignes à couvrir - Aucun test unitaire**

## Explication

Ce projet portfolio est développé dans un **contexte de formation DevOps**.

L'objectif est de démontrer les compétences en :
- ✅ Intégration continue (Jenkins)
- ✅ Analyse de code (SonarQube)
- ✅ Conteneurisation (Docker)
- ✅ Déploiement automatisé

Les tests unitaires ne sont **pas implémentés actuellement** car :
1. Focus sur l'infrastructure DevOps
2. Projet personnel (faible criticité)
3. Architecture CRUD simple

## Quality Gate adapté

Un Quality Gate personnalisé a été configuré sans exigence de couverture de tests, tout en maintenant les autres critères de qualité (pas de bugs, pas de vulnérabilités, code maintenable).

## Évolution future

Pour une mise en production, des tests seraient ajoutés avec :
- Backend : Jest + Supertest (couverture > 80%)
- Frontend : Vitest + React Testing Library (couverture > 70%)
